# scatteredpearls.studio

The website for **Scattered Pearls** — a tiny studio for lean, ad-free, pay-once apps.
No accounts, no tracking.

- **Domain:** `scatteredpearls.studio`
- **Apps as paths:** e.g. `scatteredpearls.studio/blitzfingers` (no separate per-app
  domains, by design).
- **Status:** coming soon.

Design and brand come from the shared Scattered Pearls design system; `tokens.css` and
the brand fonts are vendored into this repo.
